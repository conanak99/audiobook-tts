# Voices

By default the men use VieNeu (fast) and the heroine is cloned with Drama-3 from an **onboarded** voice (onboarded mean voice has been licensed for use). 

Pick the female voice with the user and put its id in the book's `cast.json`, e.g. `"female": "lynasa"` (see the template below).

## Onboarded Drama-3 voices

Use only these. Each voice lives in `references/voices/<id>/`:
- `reference-N.wav`: one or more cleaned cuts (≤ 30 s together; Drama-3 uses them all)
- `reference-N.txt`: the reviewed transcript of each
- `samples/sample-1..3.wav`: ~5 s auditions to play for the user
- `voice.json`: the source of truth

To add a voice from any video/audio file or link, use the **voice-onboarding** skill. To add a build note, use `python3 -m viettts voice note <id> "<what you learned>"`.

- Choose by `style`/`fits`, and play the user that voice's samples. Fewer sample retries means a more stable voice, so builds are faster with fewer repairs. Several women in one book can each get their own voice with per-speaker cast entries, e.g. `"Bạch Thanh Thanh": "nika-linh-lan"`.
- These voices are cut from public videos/streams. Personal listening is fine. Before an audiobook is shared or published, tell the user to get permission through the voice's licensing contact.

## VieNeu voices

| VieNeu voice | Style | Default role |
| --- | --- | --- |
| **Thiện Minh** | Male, Northern, storytelling | `narrator`, which also voices the MC |
| **Hải Đăng** | Male, Northern, natural | `male` (other men); the alternative narrator |
| **Thùy Dung** | Female (VieNeu) | A game system or panel (`Hệ thống`): bracket banners such as `[ĐÃ MỞ KHÓA NHIỆM VỤ: …]`, its own lowercase lines, and `▰▰▱` progress bars, which the build skips |
| **Adam bựa** | Male, comic | A comic, important side character (Liễu lão thư lại in Mị Mị v4) |

A system voice keeps banners apart from the narration without using up one of the 3 Drama-3 women. VieNeu reads banner text in capitals and the brackets without trouble, and `check` flags its lines with "female speaker uses words men say", which is expected for system text. Give the system its own speaker even when a whole banner and its description are split over two script lines. In Mị Mị v2–v6, 9–44 lines per book went to it with no failures.

Builds accept only the VieNeu voices in `VIENEU_VOICES` (`viettts/audiobook/build.py`). To use another VieNeu preset, add its name to the list first; its GGUF voice files are created on first use.

An all-Drama-3 cast (`casts/drama3.json`) gives the men the synthetic references `references/vieneu-thien-minh.wav` and `references/vieneu-hai-dang.wav`.

## Cast template

`narrator` voices the narration. The first-person MC (`ta`/`tôi`) is the same person in about 99% of stories, so his dialogue (`mc`) defaults to `thien-minh-drama`, the Drama-3 clone of the narrator Thiện Minh: the same timbre, but it takes `enhance.txt` tags. That default applies only while `narrator` is Thiện Minh; with another narrator the MC uses the narrator voice unless the cast sets `mc` (e.g. `hai-dang-drama` for Hải Đăng). `"mc": "Thiện Minh"` keeps the MC on VieNeu.

`male` is only for *other* men. Set `"mc"` to another voice only if the user wants the MC to sound different; the MC then uses that voice, whatever their pronoun.

A VieNeu name runs on VieNeu and an onboarded voice id runs on Drama-3. There is no engine setting: the voices decide it. Every key in `voices` is optional; one that is left out keeps the `casts/mixed.json` voice:

```json
{
  "voices": {
    "narrator": "Thiện Minh",
    "mc": "thien-minh-drama",
    "male": "Hải Đăng",
    "female": "shirone-mika",
    "Bạch Thanh Thanh": "nika-linh-lan"
  }
}
```

Save it as `<audiobook dir>/cast.json` and build with `--cast <audiobook dir>/cast.json`; the build has no other voice flags. Presets: `casts/mixed.json` (the default), `casts/vieneu.json`, `casts/drama3.json`.
