# Voices

By default the men use VieNeu (fast) and the heroine is cloned with Drama-3 from an **onboarded** voice (onboarded mean voice has been licensed for use). 

Pick the female voice with the user and pass its id, e.g. `--female lynasa`.

## Onboarded Drama-3 voices

Use only these. Each voice lives in `references/voices/<id>/`:
- `reference-N.wav`: one or more cleaned cuts (≤ 30 s together; Drama-3 uses them all)
- `reference-N.txt`: the reviewed transcript of each
- `samples/sample-1..3.wav`: ~5 s auditions to play for the user
- `voice.json`: the source of truth

To add a voice from any video/audio file or link, use the **voice-onboarding** skill. To add a build note, use `python3 -m viettts voice note <id> "<what you learned>"`.

- Choose by `style`/`fits`, and play the user that voice's samples. Fewer sample retries means a more stable voice, so builds are faster with fewer repairs. Several women in one book can each get their own voice with per-speaker cast entries, e.g. `"Bạch Thanh Thanh": "nika-linh-lan"`.
- These voices are cut from public videos/streams. Personal listening is fine. Before an audiobook is shared or published, tell the user to get permission through the voice's licensing contact.

## Male voices (VieNeu)

| VieNeu voice | Style | Default role |
| --- | --- | --- |
| **Thiện Minh** | Male, Northern, storytelling | `narrator`, which also voices the MC |
| **Hải Đăng** | Male, Northern, natural | `male` (other men); the alternative narrator |

Builds accept only the VieNeu voices in `VIENEU_VOICES` (`viettts/audiobook/build.py`). To use another VieNeu preset, add its name to the list first; its GGUF voice files are created on first use.

An all-Drama-3 build (`--engine drama3`) gives the men the synthetic references `references/vieneu-thien-minh.wav` and `references/vieneu-hai-dang.wav`.

## Cast template

`narrator` voices the narration **and** the first-person MC (`ta`/`tôi`). They are the same person in about 99% of stories, so they share one voice. 

`male` is only for *other* men. Don't put the MC under `male`; use `--separate-mc` only if the user wants the MC to sound different. 

A VieNeu name runs on VieNeu and an onboarded voice id runs on Drama-3:

```json
{
  "_note": "narrator = narration + first-person MC (one voice); male = other men only. VieNeu name -> VieNeu, onboarded voice id -> Drama-3",
  "voices": {
    "narrator": "Thiện Minh",
    "male": "Hải Đăng",
    "female": "shirone-mika",
    "Bạch Thanh Thanh": "nika-linh-lan"
  }
}
```

The same template is in `casts/mixed-example.json`. For a single heroine, `--female <id>` is enough and no cast file is needed.
